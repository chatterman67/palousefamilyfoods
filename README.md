# Palouse Family Foods website

This is a lightweight, multi-page static website. Open `index.html` directly or serve this folder with any static web server. No package installation or backend is required.

- Address (`215 E Main St, Palouse, WA 99161`) and phone (`(509) 878-2012`) were visible in the Google Maps business listing when this draft was prepared. Confirm both with the business before launch.

## Updating content

Edit page copy directly in the matching `.html` file. Shared visual styling is in `styles.css`; the mobile menu and footer year are handled by `script.js`. There is no contact form because this site has no configured form service or backend.
